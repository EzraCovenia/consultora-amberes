# Amberes Consultora

Sitio corporativo de Amberes Consultora y demo pública de **Amberes Intelligence™**.

## Enlaces publicados

- **Sitio corporativo:** https://ezracovenia.github.io/consultora-amberes/
- **Demo Amberes Intelligence™:** https://ezracovenia.github.io/consultora-amberes/intelligence/
- **Plantilla Excel estándar:** https://ezracovenia.github.io/consultora-amberes/intelligence/plantilla/Amberes_Plantilla_Estandar.xlsx
- **Ejemplo completo para probar la demo:** https://ezracovenia.github.io/consultora-amberes/intelligence/plantilla/Amberes_Ejemplo_Completo.xlsx

## Cómo probar la demo

1. Abre Amberes Intelligence™ desde el enlace anterior.
2. Selecciona **Cargar ejemplo** para ver un caso demostrativo, o descarga la plantilla estándar y complétala con datos de prueba.
3. Explora los módulos disponibles y prueba la exportación a Excel y PDF.
4. Revisa qué indicadores provienen del archivo y cuáles aparecen como estimados.

## Alcance y seguridad

Esta publicación es una **demo pública estática**. Los archivos se procesan en el navegador y el sitio no incorpora autenticación ni almacenamiento privado. No cargues datos personales, información de clientes, nóminas, cuentas bancarias ni estados financieros confidenciales. Para usar datos reales de clientes se requiere una solución privada con controles de acceso, seguridad y pruebas adicionales.

Los resultados son referenciales. Las cifras derivadas o marcadas como estimadas dependen de supuestos y deben validarse por un profesional antes de tomar decisiones contables, financieras, de inversión o de adquisición.
