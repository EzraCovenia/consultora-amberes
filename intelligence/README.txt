Enlace desde PROYECTOS:  <a href="intelligence/">Amberes Financial Intelligence</a>

Uso: subir UN archivo Excel (plantilla/Amberes_Modelo_Consolidado.xlsx). El software reconoce cada pestaña
(P&L, Evaluación de proyectos, Flujo de Caja, Resumen, Escenarios, Valoración, Ratios, Balance, M&A).
Con solo un P&L genera flujo de caja operacional/de inversión/financiero, balance cuadrado y valoración M&A (todo rotulado "estimado").
Si sube solo un Balance (1 o 2 períodos) o solo un Estado de Flujo de Caja, completa los otros informes de forma aproximada y lo rotula como estimado.
PDF: se genera nativamente con jsPDF + autoTable (pdf.js).
Archivos: index.html, app.js, pdf.js, app.css, intelligence.css, model.js (lectura), model-engine.js (cálculo).
Demo: no cargar información sensible en una publicación pública.
